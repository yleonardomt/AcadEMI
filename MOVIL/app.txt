=====================================================================
  ACADEMI MÓVIL - PASOS PARA PROBARLA Y PROGRAMAR EN TU CELULAR
  (Samsung A32 por cable USB, con recarga en vivo)
=====================================================================

Todos los comandos con "$" se escriben en la terminal de Ubuntu (WSL).
Los que dicen "PowerShell" se escriben en PowerShell de Windows.

---------------------------------------------------------------------
 ANTES DE EMPEZAR (una sola vez, ya está hecho)
---------------------------------------------------------------------
- Flutter, JDK 17 y Android SDK instalados en ~/development y ~/Android.
- usbipd-win instalado en Windows (pasa el celular USB hacia WSL).
- Depuración USB activada en el celular (Ajustes > Opciones de desarrollador).
- Permisos USB dados con:  sudo bash ~/setup-usb.sh
- Las variables de entorno ya están en ~/.bashrc.
  Si "flutter" no se reconoce, ejecuta:  source ~/.bashrc

---------------------------------------------------------------------
 CADA VEZ QUE QUIERAS TRABAJAR (5 pasos)
---------------------------------------------------------------------

PASO 1 - Conecta el celular por cable USB a la PC.
         Desbloquéalo. Si dice "Cargando por USB", elige
         "Transferencia de archivos".

PASO 2 - Pasa el celular de Windows a WSL.
         Abre PowerShell (como administrador la primera vez) y escribe:

           usbipd list
           usbipd attach --wsl --busid 2-4 --auto-attach

         * 2-4 es el número de tu Samsung en la lista (si cambia, usa el
           que diga "A32 de Yhonatan" / "ADB Interface").
         * Deja esa ventana de PowerShell ABIERTA: con --auto-attach el
           celular se reconecta solo si se suelta.
         * Solo la primera vez en la vida: usbipd bind --busid 2-4

PASO 3 - Comprueba que WSL ve el celular.

           $ adb devices

         Debe salir:  RF8T214ERDY   device
         - "unauthorized"  -> mira la pantalla del celular y toca
           "Permitir depuración USB" (marca "Permitir siempre").
         - lista vacía      -> repite el PASO 2.

PASO 4 - Enciende el servidor de AcadEMI (la base de datos y la API).

           $ cd ~/Academi
           $ source venv/bin/activate
           $ python manage.py runserver 0.0.0.0:80

         Déjalo corriendo en esa terminal (no la cierres).
         Para probar que vive (en otra terminal):
           $ curl localhost/api/v1/categories/

PASO 5 - Conecta el celular al servidor y abre la app.
         En una terminal nueva:

           $ adb reverse tcp:80 tcp:80
           $ cd ~/Academi/MOVIL
           $ flutter run -d RF8T214ERDY

         * "adb reverse" hace que "localhost" del celular sea tu PC.
           Hay que repetirlo cada vez que reconectes el cable.
         * La primera vez compila unos 3-4 minutos; después, segundos.

---------------------------------------------------------------------
 PROGRAMAR CON RECARGA EN VIVO
---------------------------------------------------------------------
Con "flutter run" corriendo, edita cualquier archivo de lib/ y guarda.
En la terminal de flutter run presiona:

   r   recarga en vivo (hot reload): ve el cambio en el celular al instante
   R   reinicia la app (hot restart): cuando cambias estado global
   q   sale

Si cambias cosas de pubspec.yaml (paquetes) o del AndroidManifest:
   q, y vuelve a ejecutar:  flutter run -d RF8T214ERDY

Si cambias el backend (carpeta academi/ de Django):
   Ctrl+C en la terminal del servidor y vuelve a ejecutar el PASO 4.

---------------------------------------------------------------------

---------------------------------------------------------------------
 SI ALGO FALLA
---------------------------------------------------------------------
- "adb devices" vacío
    -> repite el PASO 2 (usbipd attach). Si tocaste el cable, se soltó.
- "adb devices" dice "no permissions"
    -> sudo bash ~/setup-usb.sh   y desconecta/reconecta el cable.
- La app dice "No se pudo conectar con el servidor"
    -> 1) ¿el servidor del PASO 4 sigue corriendo?
       2) repite:  adb reverse tcp:80 tcp:80
       3) en la app, engranaje > servidor = http://127.0.0.1
- flutter run dice "Lost connection to device"
    -> el celular se soltó; repite PASOS 2, 3 y 5.
- Error de "Gradle" o cosas raras al compilar
    $ cd ~/Academi/MOVIL
    $ flutter clean
    $ flutter pub get
    $ flutter run -d RF8T214ERDY
- Ver errores de la app en vivo
    $ adb logcat | grep -i flutter
- Ver todo el estado de Flutter
    $ flutter doctor
